# Nolane Plan v0.9.0a1

## Production Correctness / Distributed Authority

`v0.9.0a1` closes the bounded Wave-9 production-correctness scope of Nolane Plan without opening a new planning architecture or making universal distributed-systems claims.

**Runtime release commit:** `d11abb4468c701622d0e78722f1a0e54c94aa920`

## Highlights

### Production-store authority

- Storage capability profiles make backend guarantees explicit.
- Authority Epochs bind backend identity/revision, writer identity and the immediately prior epoch.
- Strong multi-writer operation is admitted only where durable acknowledgement, exact-revision compare-and-swap and fencing semantics are available.
- Stale writer/epoch/revision authority fails closed.

### Destructive compaction

- Bounded destructive compaction follows **prepare → shadow verification → durable switch → conservative retirement**.
- Protected lineage, proof/evidence/debt and dormant/resurrection references are retained.
- Source retirement cannot happen before the target switch is durably observable.

### External execution contracts

- Authorization binds the exact adapter revision and capability contract.
- Dispatch acknowledgement, cancellation, fencing, reconciliation and compensation remain distinct semantic states.
- Best-effort cancellation is not promoted to clean cancellation.
- Compensation remains a new external effect; it does not erase the original one.

### Restart, replay and falsification

- Wave-9 correctness-significant sidecars survive supported restart/replay paths.
- Unknown correctness-significant replay events remain fail-closed.
- Deterministic chaos, differential equivalence, constitutional mutation and source/spec coverage gates close the release evidence surface.

## Boundaries

This release does **not** establish:

- universal distributed consensus;
- arbitrary multi-host crash safety;
- arbitrary database/storage-engine garbage collection or compaction safety;
- universal physical remote cancellation;
- durability beyond declared storage/adapter capability contracts;
- generalized arbitrary constraint-theory completeness;
- benchmark superiority over other planning systems;
- any Wave-10+ capability.

The in-memory production store remains a semantic reference backend, not a claim of production durable storage.
